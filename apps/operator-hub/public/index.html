    SELESAIKAN TEST DEVICE

    Network wajib Gateway

    TLS hanya dapat disimpan jika firmware mengidentifikasi diri sebagai TLS-capable, Root CA valid tersedia, dan sinkronisasi waktu melalui NTP dapat dilakukan. Tidak ada mode insecure TLS.

    Alarm fisik 24 V

    AUTO adalah mode default produk. MANUAL hanya untuk pengujian.

    Menunggu status

    AUTO: default setiap boot; alarm fisik mengikuti alarm inferensi yang valid. MANUAL: mode test dan perintah output ON/OFF hanya berlaku untuk sesi berjalan. Reboot selalu kembali ke AUTO dengan test output OFF. Telemetri dan radio tetap melaporkan alarm inferensi sebenarnya.

    Output fisik: menunggu status firmware

    Kontrol tetap terkunci sampai firmware melaporkan status alarm lengkap. Saat ON, firmware memberi steady 24 V; perangkat alarm eksternal membentuk pola 1 detik ON / 1 detik OFF secara internal.
